## Tujuan Praktikum

Praktikum ini digunakan untuk memahami struktur dasar HTML, tag-tag dasar HTML, serta membuat dokumen HTML.

## Langkah Praktikum

### 1. Struktur Dasar HTML

Membuat dokumen `index.html` menggunakan deklarasi `<!DOCTYPE html>`, elemen `<html>`, `<head>`, `<title>`, dan `<body>`.

### 2. Membuat Paragraf

Menambahkan beberapa paragraf menggunakan tag `<p>` dan komentar HTML untuk memberi penanda pada bagian kode.

### 3. Menambahkan Heading

Menggunakan `<h1>`, `<h2>`, dan `<h3>` sebagai judul utama, subjudul, dan judul bagian.

### 4. Memformat Teks

Mencoba tag pemformatan seperti `<b>`, `<strong>`, `<i>`, `<em>`, `<mark>`, `<small>`, `<del>`, `<ins>`, `<sub>`, `<sup>`, dan `<code>`.

### 5. Menyisipkan Gambar

Menambahkan gambar menggunakan tag `<img>` dengan atribut `src`, `width`, `alt`, dan `title`.

### 6. Menambahkan Hyperlink

Membuat hyperlink internal ke `halaman2.html`, anchor menuju bagian tertentu pada halaman dengan `id`, serta hyperlink eksternal menuju Google.

### 7. Menambahkan List

Membuat unordered list menggunakan `<ul>` dan ordered list menggunakan `<ol>`.

### 8. Menambahkan Komentar

Menambahkan komentar menggunakan format `<!-- komentar -->` untuk memberi penanda pada beberapa bagian kode.

### 9. Menggabungkan Semua Elemen

Menggabungkan heading, paragraf, pemformatan teks, gambar, hyperlink, list, dan profil mahasiswa dalam halaman `index.html` dan `halaman2.html`.
